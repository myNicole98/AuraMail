## Highlights

- Mail rules: Outlook-style conditions, exceptions and actions, applied to new mail as it arrives, with "stop processing more rules"
- Run one rule, or all of them, over the mail already sitting in a folder
- Labels: coloured tags you can assign from the message menu, create per account, and combine freely on a message
- New Categories settings tab for the AI category tabs and the labels, in one place
- The message list shows labels as coloured chips and no longer draws a sender avatar

## Fixes

- Rule and category controls no longer inherit the message-list row styling, which had made them appear only on hover, inside a stray dark background
- Every control in the rule editor shares the same height, and its dropdowns follow the app theme instead of the system widget colours
